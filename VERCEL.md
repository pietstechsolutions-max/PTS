# Put the website live on Vercel (front end only)

This deploys the public website: home, services, 4 location pages, blog.
The client portal and admin are NOT part of this deploy (they need a server + database — separate step).

## 1. Deploy (5 min)
1. Go to vercel.com → Sign up → **Continue with GitHub**.
2. **Add New… → Project** → pick the `piets-site` repo → **Import**.
3. Vercel reads `vercel.json` — leave every setting alone. Click **Deploy**.
4. You get a live URL like `piets-site.vercel.app`. Open it and check the pages.

## 2. Make the quote form work (5 min)
Without this the form tells visitors to call/text instead of silently losing the lead.
1. Google Account → Security → 2-Step Verification → **App passwords** → create one named "Website".
2. Vercel → your project → **Settings → Environment Variables**, add:
   - `SMTP_USER` = pietstechsolutions@gmail.com
   - `SMTP_PASS` = the 16-character app password
   - `OWNER_EMAIL` = pietstechsolutions@gmail.com
3. **Deployments → … → Redeploy**.
Every form submission now emails you the lead (name, phone, town, service, message) with a tap-to-call button.

## 3. Point the domain (5 min + up to 1 hr to spread)
1. Vercel → project → **Settings → Domains** → add `pietstechsolutions.com` and `www.pietstechsolutions.com`.
2. Vercel shows the records. In GoDaddy → My Products → **DNS**:
   - `A` record, name `@`, value `76.76.21.21`
   - `CNAME`, name `www`, value `cname.vercel-dns.com`
   - Delete the old `@` A record pointing at the parked page.
3. SSL is issued automatically.

## 4. After it's live
- Google Search Console → add pietstechsolutions.com → submit `https://pietstechsolutions.com/sitemap.xml`
- Bing Webmaster Tools → import from Google.
- Fill the placeholders: 3 testimonials, license # in the footer, GA4 / Meta Pixel IDs (marked `TODO (owner)` in the code).

## What's in the deploy
| File | What it does |
|---|---|
| `vercel.json` | Build + output settings, caching, security headers |
| `api/leads.js` | Emails the quote form to you |
| `public/` | The built site (regenerated by `npm run build` on every deploy) |
| `content/blog/*.md` | Blog posts — add a `.md` file, push, it appears on the site |

## Notes
- The "Client Portal" link is hidden until the portal is hosted. It comes back automatically when `PORTAL_LIVE=1` is set as an env var (and the portal is actually running).
- Blog posts are built at deploy time from `content/blog`. To publish a post: add the `.md` file, commit, push — Vercel rebuilds.
